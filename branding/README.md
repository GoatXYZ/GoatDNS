# GoatDNS brand kit

The mark turns a front-facing goat into a small routing graph: the horns form the outer paths, the center line reads as a DNS route, and four nodes keep the network idea visible without turning the goat into a circuit diagram.

## Color and type

- Goat Amber — `#FF9F1C`
- Black — `#000000`
- Wordmark — Segoe UI Variable Display Semibold, falling back to Segoe UI or the system sans serif.

Keep at least one node-width of clear space around the mark. Use the tile icon below 64 px, keep the wireframe one color, and don't add a shield, padlock, globe, or extra network mesh—the name and routing geometry already carry the product idea.

## Concept prompt

The concept reference was generated with the built-in image tool using this final prompt:

```text
Use case: logo-brand
Asset type: palette reference for a scalable app icon and identity mark
Primary request: create a simple, centered, front-facing wireframe goat head for GoatDNS using very few geometric monoline strokes
Subject details: confident angular horns, pointed ears, tapered face, and a center route with four subtle circular connection nodes; the geometry should suggest DNS routing without becoming a circuit diagram
Style/medium: flat vector-friendly logo, exact bilateral symmetry, balanced negative space, friendly rather than aggressive, recognizable at 16 pixels
Color palette: warm amber-orange linework #FF9F1C on pure black #000000; exactly these two colors, no gradients
Composition: isolated square mark with generous even padding
Constraints: no text, wordmark, badge, border, shield, padlock, globe, Wi-Fi symbol, shadow, 3D, fur, watermark, or decorative polygon mesh
```
